# Логический аудит «Штаб AI» 2.7

- Подтверждённая фактическая операция не может быть возвращена в план через меню.
- Общая сумма бюджета и распределение по статьям редактируются отдельными формами.
- Доход требует ручного названия источника; повторение дохода исключено.
- Заметки на экране «Сегодня» занимают полную ширину.
- «План» содержит только календарь и повестку выбранного дня.
- «Аналитика» вынесена в отдельную нижнюю вкладку: задачи, командировки и проекты.
- Бюджет и исполнение по статьям находятся во вкладке «Финансы».
- Помощник открывается узнаваемой кнопкой ✦ в верхней панели вместо кнопки уведомлений.
- При первом запуске APK запрашивает разрешения на уведомления и микрофон один раз.
- Разрешение Android на точные будильники запрашивается только при необходимости создания точного напоминания.
